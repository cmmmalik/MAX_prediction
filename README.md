# MAX_prediction

**MAX_prediction** is a Python library for automating the thermodynamic prediction and analysis of MAX phases and their derivatives (such as MXenes). It provides tools for calculating enthalpies, managing chemical reaction data, and handling complex phase equilibria.

## Features

- Classes and routines for:
  - Thermodynamic prediction of MAX phases
  - MXene and MAX phase reaction enumeration and analysis
  - Handling and filtering chemical species and side phases
  - Data storage and retrieval using Pickle, HDF5, and tar.gz archives
- Integration with MongoDB and ASE databases for chemical data
- Utilities for managing and logging reaction data
- Sphinx-based documentation

## Repository Structure

- **MAX_prediction/**: Main package with modules for analysis, data handling, and core logic.
- **docs/**: Sphinx documentation source and build files.
